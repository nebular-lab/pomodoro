# ポモドーロタイマー 仕様書

## 1. 目的

自分専用のポモドーロタイマー。タスクに紐付けて作業時間を計測し、「いつ、どのタスクに、どれだけ時間を使ったか」を後から確認できるようにする。

## 2. 前提

- 利用者は自分 1 人だけ。複数ユーザー・権限・共有は扱わない。
- ブラウザで使う Web アプリ。PC での利用を主とし、スマートフォンでも崩れずに操作できる。
- タスク・作業記録・設定は DB に保存し、端末やブラウザを変えても同じ内容を見られる。タイマーの状態だけは、ブラウザの中に持つ（4.2）。
- 時刻の表示と「1 日」の区切りは日本時間（JST）。保存は UTC。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| フェーズ | タイマーの 1 区間。作業・小休憩・長休憩の 3 種類 |
| ポモドーロ | 最後まで完了した作業フェーズ 1 回分 |
| サイクル | 長休憩までに行う作業フェーズの回数 |
| タスク | 作業の対象。作業フェーズに紐付ける |
| 作業記録 | 作業を実際に行っていた 1 つの連続した時間帯（開始時刻〜終了時刻） |

## 4. 機能

### 4.1 ログイン

- ID とパスワードでログインする。
- アカウントは 1 つだけで、あらかじめ用意しておく。登録画面・パスワード再設定画面は作らない。
- パスワードはハッシュ化して保存する。
- ログイン状態は Cookie のセッションで保持し、30 日間有効。ログアウトできる。
- 未ログインでは、ログイン画面以外のどの画面・API にもアクセスできない。
- 一定時間内のログインの試行回数に上限を設け、超えた場合は、時間が過ぎるまでログインを受け付けない（総当たり対策）。成功した試行も回数に含める。

### 4.2 タイマー

- フェーズは「作業 → 小休憩 → 作業 → … → 作業 → 長休憩」の順に進む。設定したサイクル数だけ作業を終えたら長休憩になり、そこで数え直す。
- 操作は、開始・一時停止・再開・スキップ（今のフェーズを打ち切って次へ）・リセット（今のフェーズを最初からやり直す）。スキップとリセットは、確認なしで実行する。スキップは、フェーズを開始する前でも行える。スキップしたあとの次のフェーズも、自動スタートの設定に従う。
- 画面には、残り時間、サイクルの進み具合（点で表す）、紐付けているタスクとその色を表示する。フェーズの種類（作業・小休憩・長休憩）は文字では表示せず、作業か休憩かを画面の色や背景で区別する。
- フェーズが終わったら、音とブラウザ通知で知らせる。ブラウザ通知の許可は、まだ許可も拒否もしていないときに、最初に開始の操作をした時点で求める。
- タイマーが動作中の間は、ブラウザのタブのタイトルの頭に、残り時間を付ける（例: 「24:52 履歴」）。
- タイマーは、ログイン後のどの画面を開いていても動き続け、フェーズが終わると音と通知で知らせる。
- 次のフェーズを自動で開始するかどうかは設定に従う（4.5）。自動開始しない場合は、次のフェーズを表示した状態で止まり、開始操作を待つ。
- タイマーはブラウザで動かし、状態（フェーズ、サイクルの何回目か、動作中か、終了予定時刻または残り時間、選択中のタスク、作業フェーズで動いていた時間帯）をブラウザの保存領域に持つ。サーバーには持たない。同じブラウザなら、ページを再読み込みしても、タブを閉じて開き直しても、経過した分を引いた残り時間から続きが見られる。別の端末や別のブラウザには引き継がれない。
- タブを閉じている間にフェーズの終了時刻を過ぎた場合、次に開いたときに、そのフェーズは予定の終了時刻で終わったものとして扱う。進めるのはその 1 フェーズだけで、次のフェーズは、自動スタートの設定に関係なく、開始前で止める。このときは、音も通知も出さない。
- 同じブラウザの複数のタブで開いたときは、タブの間でタイマーの状態をそろえる。フェーズが終わったときの音・通知・作業記録の送信は、どれか 1 つのタブだけが行う。複数のタブで同時に使うことはまれなので、それでも残る細かな食い違い（ほかのタブで変えた設定が、開き直すまで反映されない、など）は、起きても構わないものとする。
- ログアウトしたとき、またはログインの有効期限が切れてログイン画面へ移るときは、タイマーを止め、状態を消す。
- フェーズが終わったときの音は、短いチャイムを 1 回（作業でも休憩でも同じ音）。
- サイクルの途中で、設定のサイクルの回数を、いまの回以下に減らしたときは、次の休憩を長休憩にする。

### 4.3 タスク

- タスクを登録・名前変更・色の変更・アーカイブできる。削除はできない。項目は名前（50 文字まで）と色。
- タスクには色を 1 つ設定する。登録したときに、既定の 12 色の中から自動的に設定される。あとから、既定の 12 色から選ぶか、カラーピッカーで自由な色を指定して変更できる。
  - 既定の 12 色（並び順）: 赤 `#EF4444`、オレンジ `#F97316`、黄 `#EAB308`、黄緑 `#84CC16`、緑 `#22C55E`、青緑 `#14B8A6`、水色 `#06B6D4`、青 `#3B82F6`、藍 `#6366F1`、紫 `#A855F7`、ピンク `#EC4899`、茶 `#92400E`。
  - 登録したときは、使用中（アーカイブしていない）のタスクで使われている数がいちばん少ない色を設定する。同じ数の色が複数あるときは、並び順で先のものにする。
- アーカイブしたタスクは一覧から隠れるが、アーカイブを解除して一覧に戻せる。タスクに「完了」という状態はない。
- アーカイブしたタスクの作業記録は残る（履歴にはタスク名が表示され続ける）。
- タイマー画面で、これから作業するタスクを 1 つ選ぶ。タスクを選ばずに作業を始めてもよい（「タスクなし」として記録）。「タスクなし」は、固定の灰色で表示する。選んでいるタスクをアーカイブしたときは、その時点で、選択を「タスクなし」に戻す。
- 作業フェーズが動作している間は、タスクを切り替えられない。一時停止中は切り替えられる（切り替えた場合、再開後の作業記録は新しいタスクに付く）。

### 4.4 作業記録と履歴

- 作業時間は、ポモドーロが完了したとき（作業フェーズを最後まで終えたとき）に数える。そのフェーズで実際にタイマーが動いていた時間帯を、完了した時点で、ブラウザがサーバーへ送り、作業記録として保存する。
  - 保存する内容: 開始時刻、終了時刻、タスク。
  - フェーズの途中で一時停止した場合は、そこで作業記録を区切る。再開すると新しい作業記録が始まる。つまり一時停止中の時間は作業記録に含まれない。
  - スキップやリセットで打ち切った作業フェーズの時間は数えない。作業記録に残さず、どの集計にも含めない。
  - 動作中の作業フェーズの時間は、完了するまで、合計作業時間にもグラフにも現れない。
  - 送信に失敗した場合は、エラーを表示し、その回の作業記録は保存しない（送り直しはしない）。
- 休憩フェーズは記録しない。
- 履歴画面で次のことが分かる。
  - 表示する期間を、日・週・月・年で切り替える。前後の期間へ移動できる。
  - その期間の作業時間の棒グラフ（日は 1 時間ごと、週と月は 1 日ごと、年は 1 か月ごと）。棒は、タスクの色で塗り分けて積み上げる。
  - その期間の合計作業時間、完了したポモドーロ数、タスクごとの合計時間（タスクの色を添え、タスクの作成順に並べる）。
  - 作業記録を 1 件ずつ並べた一覧は表示しない。
- 作業記録は、後から変更も削除もできない（タスクの付け替え、時刻の手修正、手動追加、削除のどれも行わない）。

### 4.5 設定

| 項目 | 初期値 | 範囲 |
| --- | --- | --- |
| 作業時間 | 25 分 | 5〜120 分（5 分単位） |
| 小休憩時間 | 5 分 | 5〜60 分（5 分単位） |
| 長休憩時間 | 15 分 | 5〜60 分（5 分単位） |
| サイクル | 4 回 | 1〜10 回 |
| 休憩を自動スタートする | オフ | オン / オフ |
| 作業を自動スタートする | オフ | オン / オフ |

- 設定は DB に保存する。値を変えた時点で、すぐに保存する（保存の操作はない）。
- 時間やサイクルの変更は、次に始まるフェーズから反映する。進行中のフェーズの残り時間は変えない。

## 5. 画面

| 画面 | 内容 |
| --- | --- |
| ログイン | ID・パスワードの入力 |
| タイマー | タイマーの表示と操作、作業するタスクの選択 |
| タスク管理 | タスクの一覧、登録、名前と色の変更、アーカイブ、アーカイブの解除 |
| 履歴 | 日・週・月・年ごとの、タスクの色で塗り分けた作業時間のグラフと集計 |
| 設定 | 4.5 の項目の変更、ログアウト |

詳細は画面設計で決める。

## 6. データ

| データ | 主な項目 |
| --- | --- |
| ユーザー | ID、パスワードのハッシュ |
| セッション | ログイン状態、有効期限 |
| 設定 | 4.5 の 6 項目 |
| タスク | 名前、色、アーカイブしたかどうか、作成日時 |
| ポモドーロ | 完了した作業フェーズ 1 回分。完了した時刻 |
| 作業記録 | どのポモドーロのものか、開始時刻、終了時刻、タスク |

## 7. 今回やらないこと

- ユーザー登録、パスワード再設定、複数ユーザー対応
- タスクの期限・見積もり・タグ・プロジェクト分け・並べ替え
- 作業記録の手動追加・時刻修正・タスクの付け替え・削除、エクスポート
- 通知音やテーマの切り替え
- オフライン動作、ネイティブアプリ
