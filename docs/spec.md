# ポモドーロタイマー 仕様書

## 1. 目的

自分専用のポモドーロタイマー。タスクに紐付けて作業時間を計測し、「何時から何時まで、どの作業をしていたか」を後から確認できるようにする。

## 2. 前提

- 利用者は自分 1 人だけ。複数ユーザー・権限・共有は扱わない。
- ブラウザで使う Web アプリ。PC での利用を主とし、スマートフォンでも崩れずに操作できる。
- データは DB に保存し、端末やブラウザを変えても同じ内容を見られる。
- 時刻の表示と「1 日」の区切りは日本時間（JST）。保存は UTC。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| フェーズ | タイマーの 1 区間。作業・小休憩・長休憩の 3 種類 |
| ポモドーロ | 最後まで完了した作業フェーズ 1 回分 |
| サイクル | 長休憩までに行う作業フェーズの回数 |
| タスク | 作業の対象。作業フェーズに紐付ける |
| 作業記録 | 作業を実際に行っていた 1 つの連続した時間帯（開始時刻〜終了時刻） |

## 4. 機能

### 4.1 ログイン

- ID とパスワードでログインする。
- アカウントは 1 つだけで、あらかじめ用意しておく。登録画面・パスワード再設定画面は作らない。
- パスワードはハッシュ化して保存する。
- ログイン状態は Cookie のセッションで保持し、30 日間有効。ログアウトできる。
- 未ログインでは、ログイン画面以外のどの画面・API にもアクセスできない。
- ログインに連続で失敗した場合は、一定時間ログインを受け付けない（総当たり対策）。

### 4.2 タイマー

- フェーズは「作業 → 小休憩 → 作業 → … → 作業 → 長休憩」の順に進む。設定したサイクル数だけ作業を終えたら長休憩になり、そこで数え直す。
- 操作は、開始・一時停止・再開・スキップ（今のフェーズを打ち切って次へ）・リセット（今のフェーズを最初からやり直す）。
- 画面には、残り時間、今のフェーズの種類、サイクルの進み具合（例: 2 / 4）、紐付けているタスクを表示する。
- フェーズが終わったら、音とブラウザ通知で知らせる。
- ブラウザのタブのタイトルにも残り時間を表示する。
- 次のフェーズを自動で開始するかどうかは設定に従う（4.5）。自動開始しない場合は、次のフェーズを表示した状態で止まり、開始操作を待つ。
- タイマーの状態はサーバー側に持つ。ページを再読み込みしても、タブを閉じても、別の端末で開いても、同じ残り時間から続きが見られる。
- タブを閉じている間にフェーズの終了時刻を過ぎた場合、そのフェーズは予定の終了時刻で終わったものとして扱う。

### 4.3 タスク

- タスクを登録・名前変更・完了・削除できる。項目は名前のみ。
- 完了したタスクは一覧から隠れるが、未完了に戻せる。
- 作業記録が 1 件でもあるタスクを削除しても、作業記録は残る（履歴にはタスク名が表示され続ける）。
- タイマー画面で、これから作業するタスクを 1 つ選ぶ。タスクを選ばずに作業を始めてもよい（「タスクなし」として記録）。
- 作業フェーズの途中でもタスクを切り替えられる。切り替えた時点で作業記録を区切る。

### 4.4 作業記録と履歴

- 作業フェーズで実際にタイマーが動いていた時間帯を、作業記録として自動保存する。
  - 保存する内容: 開始時刻、終了時刻、タスク、フェーズを最後まで完了したかどうか。
  - 一時停止すると、そこで作業記録を区切る。再開すると新しい作業記録が始まる。つまり一時停止中の時間は作業記録に含まれない。
  - スキップやリセットで打ち切った場合も、そこまでの時間は作業記録に残る。
- 休憩フェーズは記録しない。
- 履歴画面で次のことが分かる。
  - 日付を選ぶと、その日の作業記録が時刻順に並ぶ（例: 10:00–10:25 仕様書を書く）。
  - その日の合計作業時間、完了したポモドーロ数、タスクごとの合計時間。
- 作業記録は後から、タスクの付け替えと削除ができる。時刻の手修正と手動追加はできない。

### 4.5 設定

| 項目 | 初期値 | 範囲 |
| --- | --- | --- |
| 作業時間 | 25 分 | 5〜120 分（5 分単位） |
| 小休憩時間 | 5 分 | 5〜60 分（5 分単位） |
| 長休憩時間 | 15 分 | 5〜60 分（5 分単位） |
| サイクル | 4 回 | 1〜10 回 |
| 休憩を自動スタートする | オフ | オン / オフ |
| 作業を自動スタートする | オフ | オン / オフ |

- 設定は DB に保存する。
- 時間やサイクルの変更は、次に始まるフェーズから反映する。進行中のフェーズの残り時間は変えない。

## 5. 画面

| 画面 | 内容 |
| --- | --- |
| ログイン | ID・パスワードの入力 |
| タイマー | タイマーの表示と操作、タスクの一覧・登録・選択、今日の作業記録の要約 |
| 履歴 | 日付ごとの作業記録と集計 |
| 設定 | 4.5 の項目の変更、ログアウト |

詳細は画面設計で決める。

## 6. データ

| データ | 主な項目 |
| --- | --- |
| ユーザー | ID、パスワードのハッシュ |
| セッション | ログイン状態、有効期限 |
| 設定 | 4.5 の 6 項目 |
| タスク | 名前、完了したかどうか、作成日時 |
| 作業記録 | 開始時刻、終了時刻、タスク、フェーズを完了したかどうか |
| タイマー状態 | 今のフェーズの種類、サイクル内の何回目か、動作中か、終了予定時刻または残り時間、選択中のタスク |

## 7. 今回やらないこと

- ユーザー登録、パスワード再設定、複数ユーザー対応
- タスクの期限・見積もり・タグ・プロジェクト分け・並べ替え
- 週・月単位のグラフや統計
- 作業記録の手動追加と時刻修正、エクスポート
- 通知音やテーマの切り替え
- オフライン動作、ネイティブアプリ

## 8. 技術構成

| 対象 | 採用するもの |
| --- | --- |
| フレームワーク | TanStack Start（API はサーバールートで REST API として作る） |
| ログイン | Better Auth |
| DB | Cloudflare D1（Drizzle ORM 経由） |
| ホスティング先 | Cloudflare Workers |
