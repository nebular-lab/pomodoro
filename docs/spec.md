# ポモドーロタイマー 仕様書

## 1. 目的

自分専用のポモドーロタイマー。タスクに紐付けて作業時間を計測し、「いつ、どのタスクに、どれだけ時間を使ったか」を後から確認できるようにする。

## 2. 前提

- 利用者は自分 1 人だけ。
- ブラウザで使う Web アプリ。PC での利用を主とし、スマートフォンでも崩れずに操作できる。
- ブラウザだけで完結させる。サーバー・データベース・ログインは持たない。
- データ（タスク、作業記録、設定、タイマーの状態）は、すべて、そのブラウザの保存領域に持つ。
  - 別の端末や別のブラウザからは、同じ内容を見られない。
  - ブラウザの閲覧データを消す、ブラウザを変える、などでデータは失われる。控えを取る機能（書き出し・読み込み）は持たない。
- 同じブラウザの複数のタブで同時に使うことは、考えない（タブの間でタイマーの状態はそろえない）。
- 時刻の表示と「1 日」の区切りは日本時間（JST）。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| フェーズ | タイマーの 1 区間。作業・小休憩・長休憩の 3 種類 |
| ポモドーロ | 最後まで完了した作業フェーズ 1 回分 |
| サイクル | 長休憩までに行う作業フェーズの回数 |
| タスク | 作業の対象。作業フェーズに紐付ける |
| 作業記録 | 完了したポモドーロ 1 回分の記録（完了した時刻、タスク、作業した時間） |

## 4. 機能

### 4.1 タイマー

- フェーズは「作業 → 小休憩 → 作業 → … → 作業 → 長休憩」の順に進む。設定したサイクル数だけ作業を終えたら長休憩になり、そこで数え直す。スキップした作業も、サイクルの 1 回として数える。
- 操作は、開始・一時停止・再開・スキップ（今のフェーズを打ち切って次へ）・リセット（今のフェーズを最初からやり直す）。スキップとリセットは、確認なしで実行する。スキップは、フェーズを開始する前でも行える。スキップしたあとの次のフェーズも、自動スタートの設定に従う。
- 画面には、残り時間、サイクルの進み具合（点で表す）、紐付けているタスクとその色を表示する。フェーズの種類（作業・小休憩・長休憩）は文字では表示せず、作業か休憩かを画面の色や背景で区別する。
- タイマーが動作中の間は、ブラウザのタブのタイトルの頭に、残り時間を付ける（例: 「24:52 履歴」）。
- タイマーは、どの画面を開いていても動き続ける。
- タイマーの状態（フェーズ、サイクルの何回目か、動作中か、フェーズの長さ、終了予定時刻または残り時間、選択中のタスク）は、ブラウザの保存領域に持つ。ページを再読み込みしても、タブを閉じて開き直しても、経過した分を引いた残り時間から続きが見られる。フェーズの長さは、そのフェーズを開始するときに、設定から決める。
- フェーズの終わり方の規則は 1 つだけにする。終了予定時刻を過ぎていたら、そのフェーズは、終了予定時刻に完了したものとして扱う。
  - 完了に気づいたのが、終了予定時刻から 1 分以内のとき: 音とブラウザ通知で知らせる。次のフェーズを自動で開始するかどうかは、設定に従う（4.4）。自動開始しない場合は、次のフェーズを表示した状態で止まり、開始操作を待つ。
  - 1 分より遅れて気づいたとき（タブを閉じていた、PC がスリープしていた、など）: 音も通知も出さず、自動スタートの設定に関係なく、次のフェーズの開始前で止める。
- フェーズが終わったときの音は、短いチャイムを 1 回（作業でも休憩でも同じ音）。ブラウザ通知の許可は、まだ許可も拒否もしていないときに、最初に開始の操作をした時点で求める。
- サイクルの途中で、設定のサイクルの回数を、いまの回以下に減らしたときは、次の休憩を長休憩にする。

### 4.2 タスク

- タスクを登録・名前変更・色の変更・アーカイブできる。削除はできない。項目は名前（50 文字まで）と色。
- タスクには色を 1 つ設定する。登録したときに、既定の 12 色の中から自動的に設定される。あとから、既定の 12 色から選ぶか、カラーピッカーで自由な色を指定して変更できる。
  - 既定の 12 色（並び順）: 赤 `#EF4444`、オレンジ `#F97316`、黄 `#EAB308`、黄緑 `#84CC16`、緑 `#22C55E`、青緑 `#14B8A6`、水色 `#06B6D4`、青 `#3B82F6`、藍 `#6366F1`、紫 `#A855F7`、ピンク `#EC4899`、茶 `#92400E`。
  - 登録したときは、使用中（アーカイブしていない）のタスクで使われている数がいちばん少ない色を設定する。同じ数の色が複数あるときは、並び順で先のものにする。
- アーカイブしたタスクは一覧から隠れるが、アーカイブを解除して一覧に戻せる。タスクに「完了」という状態はない。
- アーカイブしたタスクの作業記録は残る（履歴にはタスク名が表示され続ける）。
- タイマー画面で、これから作業するタスクを 1 つ選ぶ。タスクを選ばずに作業を始めてもよい（「タスクなし」として記録）。「タスクなし」は、固定の灰色で表示する。
- タスクは、作業フェーズを開始したときに決まり、そのフェーズが終わるまで（一時停止中を含む）切り替えられない。開始する前と、休憩フェーズの間は、切り替えられる。
- 選んでいるタスクがアーカイブされていたときは、選択を「タスクなし」に戻す（進行中の作業フェーズがあるときは、そのフェーズが終わってから）。

### 4.3 作業記録と履歴

- 作業時間は、ポモドーロが完了したとき（作業フェーズを最後まで終えたとき）に数える。1 回のポモドーロを、1 件の作業記録にする。
  - 保存する内容: 完了した時刻（終了予定時刻）、タスク、作業した時間（その作業フェーズの長さ）。
  - 途中で一時停止しても、作業記録は分けない。一時停止していた時間は、作業した時間に含まれない。
  - スキップやリセットで打ち切った作業フェーズの時間は数えない。作業記録に残さず、どの集計にも含めない。
  - 動作中の作業フェーズの時間は、完了するまで、合計作業時間にもグラフにも現れない。
- 休憩フェーズは記録しない。
- 履歴画面で次のことが分かる。
  - 表示する期間を、日・週・月・年で切り替える。前後の期間へ移動できる。今日を含む期間より先へは進めない。
  - その期間の作業時間の棒グラフ（日は 1 時間ごと、週と月は 1 日ごと、年は 1 か月ごと）。棒は、タスクの色で塗り分けて積み上げる。作業記録は、完了した時刻が入る棒に、作業した時間のすべてを数える（10:50 に始めて 11:15 に完了した 25 分は、11 時台の棒に入る）。
  - その期間の合計作業時間、完了したポモドーロ数、タスクごとの合計時間（タスクの色を添え、タスクの作成順に並べる）。
  - 作業記録を 1 件ずつ並べた一覧は表示しない。
- 作業記録は、後から変更も削除もできない（タスクの付け替え、時刻の手修正、手動追加、削除のどれも行わない）。

### 4.4 設定

| 項目 | 初期値 | 範囲 |
| --- | --- | --- |
| 作業時間 | 25 分 | 5〜120 分（5 分単位） |
| 小休憩時間 | 5 分 | 5〜60 分（5 分単位） |
| 長休憩時間 | 15 分 | 5〜60 分（5 分単位） |
| サイクル | 4 回 | 1〜10 回 |
| 休憩を自動スタートする | オフ | オン / オフ |
| 作業を自動スタートする | オフ | オン / オフ |

- 値を変えた時点で、すぐに保存する（保存の操作はない）。
- 時間やサイクルの変更は、次に開始するフェーズから反映する。進行中のフェーズの残り時間は変えない。

## 5. 画面

| 画面 | 内容 |
| --- | --- |
| タイマー | タイマーの表示と操作、作業するタスクの選択 |
| タスク管理 | タスクの一覧、登録、名前と色の変更、アーカイブ、アーカイブの解除 |
| 履歴 | 日・週・月・年ごとの、タスクの色で塗り分けた作業時間のグラフと集計 |
| 設定 | 4.4 の項目の変更 |

詳細は画面設計で決める。

## 6. データ

すべて、ブラウザの保存領域に持つ。保存先・キー・値の形式は、[ブラウザストレージ一覧](screens/storage.md)に書く。

| データ | 主な項目 |
| --- | --- |
| 設定 | 4.4 の 6 項目 |
| タスク | ID、名前、色、アーカイブしたかどうか、作成日時 |
| 作業記録 | 完了した時刻、タスク、作業した時間 |
| タイマーの状態 | フェーズ、サイクルの何回目か、動作中か、フェーズの長さ、終了予定時刻または残り時間、選択中のタスク |

## 7. 今回やらないこと

- サーバー、データベース、ログイン、複数の端末での同期
- データの書き出しと読み込み
- タスクの期限・見積もり・タグ・プロジェクト分け・並べ替え・削除
- 作業記録の手動追加・時刻修正・タスクの付け替え・削除
- 通知音やテーマの切り替え
- ネイティブアプリ
