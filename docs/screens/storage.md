# ブラウザストレージ一覧

画面がブラウザに保存する値。画面設計書からは ID で参照する。キーに変数を持つものはない。

このアプリは、サーバーを持たない。データは、すべて、次の 4 つに持つ。

| ID | 保存先 | キー | 内容 | 値の形式 | 保存期間 |
| --- | --- | --- | --- | --- | --- |
| STG-001 | localStorage | `pomodoro:settings` | 設定 | JSON（下の「値の構造」） | 消すまで残る |
| STG-002 | localStorage | `pomodoro:tasks` | タスク（すべてのタスクの並び） | JSON の配列。要素は、下の「値の構造」 | 消すまで残る |
| STG-003 | localStorage | `pomodoro:records` | 作業記録（完了したポモドーロの並び） | JSON の配列。要素は、下の「値の構造」 | 消すまで残る |
| STG-004 | localStorage | `pomodoro:timer` | タイマーの状態 | JSON（下の「値の構造」） | 消すまで残る |

## 値の構造

値が JSON などの構造を持つものだけを書く。

読むときに、形式に合わなかった値や配列の要素（必須のフィールドがない、型が違う、範囲の外）は、使わない。その扱いは、読む画面の手順に書く。使わなかった値や要素は、次に同じ ID へ保存するときに、残さない（読めた分だけを保存する）。

### STG-001

| フィールド | 型 | 必須 | 内容 |
| --- | --- | --- | --- |
| `workMinutes` | number | ○ | 作業時間（分）。5〜120 の 5 刻みの整数。初期値は 25 |
| `shortBreakMinutes` | number | ○ | 小休憩時間（分）。5〜60 の 5 刻み。初期値は 5 |
| `longBreakMinutes` | number | ○ | 長休憩時間（分）。5〜60 の 5 刻み。初期値は 15 |
| `cycles` | number | ○ | サイクル（長休憩までに行う作業フェーズの回数）。1〜10 の整数。初期値は 4 |
| `autoStartBreak` | boolean | ○ | 休憩を自動スタートするか。初期値は `false` |
| `autoStartWork` | boolean | ○ | 作業を自動スタートするか。初期値は `false` |

### STG-002

配列の要素（タスク 1 件）。配列の並び順は、作成日時の古い順。

| フィールド | 型 | 必須 | 内容 |
| --- | --- | --- | --- |
| `id` | string（UUID） | ○ | タスクの ID。追加するときに、ブラウザが作る |
| `name` | string | ○ | タスクの名前。前後の空白を除いて、1〜50 文字 |
| `color` | string（`#RRGGBB`） | ○ | タスクの色。英字は大文字にそろえる（`#EF4444`） |
| `archived` | boolean | ○ | アーカイブしたかどうか |
| `createdAt` | string（ISO 8601、UTC） | ○ | 作成日時 |

### STG-003

配列の要素（作業記録 1 件）。配列の並び順は、足した順。

| フィールド | 型 | 必須 | 内容 |
| --- | --- | --- | --- |
| `completedAt` | string（ISO 8601、UTC） | ○ | 完了した時刻（その作業フェーズの終了予定時刻） |
| `taskId` | string または null | ○ | その作業フェーズで選んでいたタスクの ID（STG-002 の `id`）。「タスクなし」のときは `null` |
| `seconds` | number | ○ | 作業した秒数（その作業フェーズの長さ） |

### STG-004

設計書では、フィールドを、内容の先頭に書いた名前（「フェーズ」「動作」など）で呼ぶ。

| フィールド | 型 | 必須 | 内容 |
| --- | --- | --- | --- |
| `phase` | string | ○ | フェーズ。`work`（作業）、`shortBreak`（小休憩）、`longBreak`（長休憩）のどれか |
| `cycle` | number | ○ | サイクルの回。いまの作業フェーズ（休憩フェーズなら、直前の作業フェーズ）が、サイクルの何回目か。1 から始まる |
| `status` | string | ○ | 動作。`idle`（開始前）、`running`（動作中）、`paused`（一時停止中）のどれか |
| `phaseSeconds` | number または null | ○ | フェーズの長さ（秒）。フェーズを開始するときに、設定（STG-001）から決める。開始前は `null` |
| `endsAt` | string（ISO 8601、UTC）または null | ○ | 終了予定時刻。動作中だけ持つ。それ以外は `null` |
| `remainingSeconds` | number または null | ○ | 残り秒数。一時停止中だけ持つ。それ以外は `null` |
| `taskId` | string または null | ○ | 選択中のタスクの ID（STG-002 の `id`）。「タスクなし」のときは `null` |
