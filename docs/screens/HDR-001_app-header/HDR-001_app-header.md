## 1. 概要

ログインして使う画面の、いちばん上に置くヘッダー。サービス名と、タイマー・タスク管理・履歴・設定の各画面へのリンクを表示する。ポモドーロタイマーを動かす処理も、このヘッダーが受け持つ。

## 2. 変数

ヘッダーを置く画面が、設計書の冒頭の表の「共通ヘッダー」で値を指定する。

| 変数 | 内容 |
| --- | --- |
| `{v1}` | いまの画面のリンクの文言（「タイマー」「タスク管理」「履歴」「設定」のどれか） |

## 4. 初期表示時の処理

ヘッダーを置く画面を開いたときに行う。設定の値（`GET /api/settings`）は、ヘッダーが自分で取る。ヘッダーを置く画面がこの値を使うときは、ヘッダーが取ったものを使う。

この処理とアクションでは、次の「タイマーの状態」を使う。タイマーの状態は、ブラウザの保存領域に持つ。

| タイマーの状態 | 内容 |
| --- | --- |
| フェーズ | 作業・小休憩・長休憩のどれか |
| サイクルの回 | いまの作業フェーズ（休憩フェーズなら、直前の作業フェーズ）が、サイクルの何回目か。1 から始まる |
| 動作 | 開始前・動作中・一時停止中のどれか |
| 終了予定時刻 | 動作中のときに持つ。フェーズが終わる時刻 |
| 残り秒数 | 開始前と一時停止中のときに持つ |
| 選択中のタスク | SCR-002 タイマーで選んでいるタスクの ID。「タスクなし」のときは持たない |
| 作業の時間帯 | 作業フェーズで、タイマーが動いていた時間帯の並び。それぞれ、開始時刻・終了時刻・タスクの ID（「タスクなし」のときは持たない）を持つ。動作中は、最後の時間帯の終了時刻がまだない |

「フェーズの長さ」は、設定から決まる秒数（作業は `GET /api/settings` の `workMinutes`、小休憩は `shortBreakMinutes`、長休憩は `longBreakMinutes` の、それぞれ × 60）。

1. `GET /api/settings`（operationId: `getSettings`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | 設定の値を保持する |
   | 401 | ブラウザの保存領域のタイマーの状態を消して、SCR-001 ログインへ遷移して終了する |
   | 上記以外 | 設定を読み込めなかったものとして終了する（タイマーの状態を読まず、タイマーを動かす処理も行わない。ヘッダーを置く画面が SCR-002 タイマーか SCR-005 設定のときは、その画面が読み込みのエラーを表示する。SCR-003 タスク管理と SCR-004 履歴では、何も表示しない） |

2. ブラウザの保存領域から、タイマーの状態を読む。保存されていないときは、最初の状態（フェーズは作業、サイクルの回は 1、動作は開始前、残り秒数は作業フェーズの長さ、選択中のタスクなし、作業の時間帯なし）を作る。
3. 動作が開始前のとき、残り秒数を、いまの設定での、そのフェーズの長さにする。
4. 動作が動作中で、終了予定時刻を過ぎているとき（タブを閉じている間にフェーズが終わったとき）、A5 の手順 3〜8 を行う。音と通知は出さず、次のフェーズは、自動スタートの設定に関係なく、開始前で止める。進めるのは、この 1 フェーズだけにする。この処理を行うのは、どれか 1 つのタブだけにする（同時に開いたほかのタブが先に進めていたときは、何もしない）。
5. タイマーの状態を、ブラウザの保存領域に保存する。
6. 動作が動作中のとき、A7 を 1 回行う（`document.title` に残り時間を付ける）。

## 5. アクション

### アクション一覧

| ID | 操作 | 対象 |
| --- | --- | --- |
| A1 | 「タイマー」リンク押下 | No.3 |
| A2 | 「タスク管理」リンク押下 | No.4 |
| A3 | 「履歴」リンク押下 | No.5 |
| A4 | 「設定」リンク押下 | No.6 |
| A5 | タイマーの残り時間が 0 になる | - |
| A6 | ほかのタブで、タイマーの状態が変わる | - |
| A7 | タイマーが動作中に、1 秒たつ | - |

### A1. 「タイマー」リンク押下

1. ヘッダーを置く画面が SCR-002 タイマー のとき（`{v1}` が「タイマー」のとき）は、何もせずに終了する。
2. SCR-002 タイマーへ遷移する。

### A2. 「タスク管理」リンク押下

1. ヘッダーを置く画面が SCR-003 タスク管理 のとき（`{v1}` が「タスク管理」のとき）は、何もせずに終了する。
2. SCR-003 タスク管理へ遷移する（URL クエリは付けない）。

### A3. 「履歴」リンク押下

1. ヘッダーを置く画面が SCR-004 履歴 のとき（`{v1}` が「履歴」のとき）は、何もせずに終了する。
2. SCR-004 履歴へ遷移する（URL クエリは付けない）。

### A4. 「設定」リンク押下

1. ヘッダーを置く画面が SCR-005 設定 のとき（`{v1}` が「設定」のとき）は、何もせずに終了する。
2. SCR-005 設定へ遷移する。

### A5. タイマーの残り時間が 0 になる

動作が動作中で、現在の時刻が終了予定時刻に達したときに行う。

1. ブラウザの保存領域から、タイマーの状態を読み直す。保存されていないとき（ほかのタブでログアウトしたとき）は、SCR-001 ログインへ遷移して終了する。ほかのタブが先にこの処理を行っていたとき（動作中でなくなっている、または終了予定時刻が変わっているとき）は、A6 を行って終了する。この処理を行うのは、どれか 1 つのタブだけにする。
2. 短いチャイムを 1 回鳴らす（終わったフェーズが作業でも休憩でも、同じ音）。ブラウザ通知が許可されているときは、ブラウザ通知も出す。文言は、終わったフェーズが作業なら MSG-008、休憩（小休憩・長休憩）なら MSG-009。
3. 終わったフェーズが作業のとき、最後の作業の時間帯の終了時刻を、終了予定時刻にする。
4. 終わったフェーズが作業のとき、`POST /api/pomodoros`（operationId: `createPomodoro`）を呼ぶ。応答を待たずに、次の手順へ進む。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | body | `segments[].startedAt` | 作業の時間帯の開始時刻 |
   | body | `segments[].endedAt` | 作業の時間帯の終了時刻 |
   | body | `segments[].taskId` | 作業の時間帯のタスクの ID（「タスクなし」のときは `null`） |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 201 | 何もしない |
   | 401 | ブラウザの保存領域のタイマーの状態を消して、SCR-001 ログインへ遷移する |
   | 422 | MSG-007 をトーストで表示する（その回の作業記録は保存されない。送り直さない） |
   | 上記以外 | MSG-007 をトーストで表示する（その回の作業記録は保存されない。送り直さない） |

5. 作業の時間帯をすべて捨てる。
6. 次のフェーズへ進める。

   | いまのフェーズ | 条件 | 次のフェーズ | 次のサイクルの回 |
   | --- | --- | --- | --- |
   | 作業 | サイクルの回が `GET /api/settings` の `cycles` より小さい | 小休憩 | 変えない |
   | 作業 | サイクルの回が `GET /api/settings` の `cycles` 以上 | 長休憩 | 変えない |
   | 小休憩 | - | 作業 | 1 増やす |
   | 長休憩 | - | 作業 | 1 にする |

7. 動作を開始前にし、残り秒数を、いまの設定での、次のフェーズの長さにする。
8. タイマーの状態を、ブラウザの保存領域に保存する。
9. 次のフェーズを自動スタートする設定でないとき（次のフェーズが休憩なら `GET /api/settings` の `autoStartBreak`、作業なら `autoStartWork` が `false` のとき）、手順 12 へ進む。
10. 終了予定時刻を「現在の時刻 ＋ 残り秒数」にし、動作を動作中にする。次のフェーズが作業のときは、作業の時間帯を 1 つ足す（開始時刻は現在の時刻、タスクは選択中のタスク、終了時刻はまだなし）。
11. タイマーの状態を、ブラウザの保存領域に保存する。
12. ヘッダーを置く画面が SCR-002 タイマーのとき、SCR-002 の A8 を行う（表示を、変えたあとの状態に合わせる）。
13. A7 を 1 回行う（`document.title` を、変えたあとの状態に合わせる）。

### A6. ほかのタブで、タイマーの状態が変わる

同じブラウザのほかのタブが、ブラウザの保存領域のタイマーの状態を書き換えたとき、または消したときに行う。

複数のタブで開いたときに起きうる、次の食い違いには対処しない（複数のタブで同時に使うことは、まれなため）。

- すでに開いているタブが、残り時間が 0 になったときの処理（A5）をする前に、別のタブを新しく開くと、新しいタブが先に「4. 初期表示時の処理」の手順 4 で処理する。その場合、音も通知も出ず、次のフェーズは自動スタートしない。
- ほかのタブで設定を変えても、このタブは、画面を開いたときに取った設定の値を使い続ける。開き直すまで、新しい設定は反映されない。
- ほかのタブで、SCR-002 タイマーを開いたあとに作ったタスクが選ばれたとき、このタブの SCR-002 の「作業するタスク」の選択欄には、そのタスクの選択肢がない。この場合の表示は決めない。

1. ブラウザの保存領域から、タイマーの状態を読み直す。保存されていないとき（ほかのタブでログアウトしたとき）は、SCR-001 ログインへ遷移して終了する。
2. 読み直した状態を、このタブのタイマーの状態にする。
3. ヘッダーを置く画面が SCR-002 タイマーのとき、SCR-002 の A8 を行う（表示を、変えたあとの状態に合わせる）。
4. A7 を 1 回行う（`document.title` を、変えたあとの状態に合わせる）。

### A7. タイマーが動作中に、1 秒たつ

動作が動作中の間、1 秒ごとに行う。動作が動作中でなくなったとき（A5、A6、SCR-002 タイマーのアクション）にも、1 回行う。

1. 動作が動作中のとき、`document.title` を「{残り時間} {ヘッダーを置く画面の document.title}」にする（例: 「24:52 履歴」）。残り時間は、終了予定時刻から現在の時刻を引いた秒数（1 秒未満は切り上げ。0 より小さいときは 0）を「MM:SS」で表示する（分も秒も 2 桁にそろえる。100 分以上のときは、分を 3 桁で表示する）。
2. 動作が動作中でないとき、`document.title` を、ヘッダーを置く画面の `document.title` にする。
