## 1. 概要

すべての画面の、いちばん上に置くヘッダー。サービス名と、タイマー・タスク管理・履歴・設定の各画面へのリンクを表示する。ポモドーロタイマーを動かす処理も、このヘッダーが受け持つ。

## 2. 変数

ヘッダーを置く画面が、設計書の冒頭の表の「共通ヘッダー」で値を指定する。

| 変数 | 内容 |
| --- | --- |
| `{v1}` | いまの画面のリンクの文言（「タイマー」「タスク管理」「履歴」「設定」のどれか） |

## 4. 初期表示時の処理

ヘッダーを置く画面を開いたときに行う。

このアプリは、API を呼ばない。データは、すべて、ブラウザの保存領域に持つ。持つものは、次の 4 つ。どの画面の設計書でも、この名前で呼ぶ。

| ブラウザに持つもの | 内容 |
| --- | --- |
| 設定 | 作業時間（分）、小休憩時間（分）、長休憩時間（分）、サイクル（回）、休憩を自動スタートするか、作業を自動スタートするか。保存されていないときは、初期値（25、5、15、4、しない、しない）を使う |
| タスク | タスクの並び。それぞれ、ID・名前・色（`#RRGGBB`）・アーカイブしたかどうか・作成日時を持つ |
| 作業記録 | 完了したポモドーロの並び。それぞれ、完了した時刻・タスクの ID（「タスクなし」のときは持たない）・作業した秒数を持つ |
| タイマーの状態 | 下の表の 6 項目 |

| タイマーの状態 | 内容 |
| --- | --- |
| フェーズ | 作業・小休憩・長休憩のどれか |
| サイクルの回 | いまの作業フェーズ（休憩フェーズなら、直前の作業フェーズ）が、サイクルの何回目か。1 から始まる |
| 動作 | 開始前・動作中・一時停止中のどれか |
| フェーズの長さ | いまのフェーズの長さ（秒）。フェーズを開始するときに、設定から決める（作業は作業時間、小休憩は小休憩時間、長休憩は長休憩時間の、それぞれ × 60）。開始前は持たない |
| 終了予定時刻、残り秒数 | 動作中は、終了予定時刻を持つ。一時停止中は、残り秒数を持つ。開始前は、どちらも持たない（残り時間の表示には、設定での、いまのフェーズの長さを使う） |
| 選択中のタスク | SCR-002 タイマーで選んでいるタスクの ID。「タスクなし」のときは持たない |

1. ブラウザの保存領域から、タイマーの状態を読む。保存されていないときは、最初の状態（フェーズは作業、サイクルの回は 1、動作は開始前、選択中のタスクなし）を作り、保存する。
2. 動作が動作中のとき、A5 を 1 回行う（終了予定時刻を過ぎていれば、フェーズを完了にする）。

## 5. アクション

### アクション一覧

| ID | 操作 | 対象 |
| --- | --- | --- |
| A1 | 「タイマー」リンク押下 | No.3 |
| A2 | 「タスク管理」リンク押下 | No.4 |
| A3 | 「履歴」リンク押下 | No.5 |
| A4 | 「設定」リンク押下 | No.6 |
| A5 | タイマーが動作中に、1 秒たつ | - |
| A6 | フェーズが完了する | - |

### A1. 「タイマー」リンク押下

1. ヘッダーを置く画面が SCR-002 タイマーのとき（`{v1}` が「タイマー」のとき）は、何もせずに終了する。
2. SCR-002 タイマーへ遷移する。

### A2. 「タスク管理」リンク押下

1. ヘッダーを置く画面が SCR-003 タスク管理のとき（`{v1}` が「タスク管理」のとき）は、何もせずに終了する。
2. SCR-003 タスク管理へ遷移する（URL クエリは付けない）。

### A3. 「履歴」リンク押下

1. ヘッダーを置く画面が SCR-004 履歴のとき（`{v1}` が「履歴」のとき）は、何もせずに終了する。
2. SCR-004 履歴へ遷移する（URL クエリは付けない）。

### A4. 「設定」リンク押下

1. ヘッダーを置く画面が SCR-005 設定のとき（`{v1}` が「設定」のとき）は、何もせずに終了する。
2. SCR-005 設定へ遷移する。

### A5. タイマーが動作中に、1 秒たつ

動作が動作中の間、1 秒ごとに行う。ブラウザのタブが表に戻ったときにも行う（裏にある間は、ブラウザが 1 秒ごとの処理を間引くため）。

1. 現在の時刻が終了予定時刻を過ぎているとき、A6 を行って終了する。
2. `document.title` を「{残り時間} {ヘッダーを置く画面の document.title}」にする（例: 「24:52 履歴」）。残り時間は、終了予定時刻から現在の時刻を引いた秒数（1 秒未満は切り上げ）を「MM:SS」で表示する（分も秒も 2 桁にそろえる。100 分以上のときは、分を 3 桁で表示する）。
3. ヘッダーを置く画面が SCR-002 タイマーのとき、SCR-002 の No.1 も、同じ残り時間で表示する。

### A6. フェーズが完了する

A5 の手順 1 から行う。フェーズは、終了予定時刻に完了したものとして扱う。

1. 遅れ（現在の時刻 − 終了予定時刻）を求める。
2. 完了したフェーズが作業のとき、作業記録を 1 件足す（完了した時刻は終了予定時刻、タスクは選択中のタスク、作業した秒数はフェーズの長さ）。
3. 次のフェーズへ進める。

   | いまのフェーズ | 条件 | 次のフェーズ | 次のサイクルの回 |
   | --- | --- | --- | --- |
   | 作業 | サイクルの回が、設定のサイクルより小さい | 小休憩 | 変えない |
   | 作業 | サイクルの回が、設定のサイクル以上 | 長休憩 | 変えない |
   | 小休憩 | - | 作業 | 1 増やす |
   | 長休憩 | - | 作業 | 1 にする |

4. 動作を開始前にする。
5. 遅れが 60 秒以内のとき、短いチャイムを 1 回鳴らす（完了したフェーズが作業でも休憩でも、同じ音）。ブラウザ通知が許可されているときは、ブラウザ通知も出す。文言は、完了したフェーズが作業なら MSG-008、休憩（小休憩・長休憩）なら MSG-009。遅れが 60 秒を超えるときは、音も通知も出さない。
6. 遅れが 60 秒以内で、次のフェーズを自動スタートする設定のとき（次のフェーズが休憩なら「休憩を自動スタートする」、作業なら「作業を自動スタートする」がオンのとき）、次のフェーズを開始する（フェーズの長さを、設定での、そのフェーズの長さにし、終了予定時刻を「現在の時刻 ＋ フェーズの長さ」にし、動作を動作中にする）。それ以外のときは、開始前のままにする。
7. タイマーの状態と作業記録を、ブラウザの保存領域に保存する。
8. `document.title` を、変えたあとの状態に合わせる（動作中なら A5 の手順 2 のとおり。動作中でなければ、ヘッダーを置く画面の `document.title`）。ヘッダーを置く画面が SCR-002 タイマーのときは、SCR-002 の A7 を行う（「4. 初期表示時の処理」の手順 2 から行ったときは、行わない。SCR-002 の初期表示時の処理が表示する）。
