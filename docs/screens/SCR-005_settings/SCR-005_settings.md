## 5. 初期表示時の処理

設定の値（`GET /api/settings`）は、共通ヘッダーが初期表示時の処理で取ったものを使う。この画面からは呼ばない。

1. No.2、No.15、No.16 と、No.3〜No.13 を非表示にする。
2. 入力項目の位置に No.14 を表示する。
3. 共通ヘッダーの初期表示時の処理が終わるのを待つ。共通ヘッダーが設定を読み込めなかったときは、No.14 を非表示にし、MSG-005（v1: 設定）を No.15 に表示し、No.16 を表示して終了する。
4. No.14 を非表示にする。
5. 共通ヘッダーが保持している設定の値（`GET /api/settings` のレスポンス）を No.4、No.6、No.8、No.10、No.11、No.12 に入れ、No.3〜No.13 を表示する。

### A1. 設定の値を変える

値を変えた時点で行う（保存のボタンはない）。

1. No.2 を非表示にする。
2. `PATCH /api/settings`（operationId: `updateSettings`）を呼ぶ。変えた項目だけを送る。前の呼び出しの応答が返る前に、続けて別の値を変えたときも、入力項目は非活性にせず、そのつど呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | body | `workMinutes` | No.4 を変えたとき、No.4 で選んだ値。それ以外のときは送らない |
   | body | `shortBreakMinutes` | No.6 を変えたとき、No.6 で選んだ値。それ以外のときは送らない |
   | body | `longBreakMinutes` | No.8 を変えたとき、No.8 で選んだ値。それ以外のときは送らない |
   | body | `cycles` | No.10 を変えたとき、No.10 で選んだ値。それ以外のときは送らない |
   | body | `autoStartBreak` | No.11 を変えたとき、チェックありなら `true`、なしなら `false`。それ以外のときは送らない |
   | body | `autoStartWork` | No.12 を変えたとき、チェックありなら `true`、なしなら `false`。それ以外のときは送らない |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | 共通ヘッダーが保持している設定の値を、返ってきた値にする（タイマーは、次に始まるフェーズから、新しい設定を使う。進行中のフェーズの残り時間は変えない） |
   | 401 | ブラウザの保存領域のタイマーの状態を消して、SCR-001 ログインへ遷移する |
   | 422 | MSG-010 を No.2 に表示する（レスポンスの `code` は `INVALID_REQUEST`。`code` による出し分けはしない）<br>変えた項目を、共通ヘッダーが保持している設定の値に戻す |
   | 上記以外 | MSG-004 を No.2 に表示する<br>変えた項目を、共通ヘッダーが保持している設定の値に戻す |

### A2. 「ログアウト」ボタン押下

1. No.2 を非表示にする。
2. No.13 を非活性にする。
3. `POST /api/auth/sign-out`（operationId: `signOut`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | body | `callbackURL` | 指定しない |
   | body | `disableRedirect` | 指定しない |
   | body | `state` | 指定しない |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | ブラウザの保存領域のタイマーの状態を消す（動作中でも止める。途中のフェーズの時間は捨てる）<br>SCR-001 ログインへ遷移する（ブラウザの履歴を置き換える） |
   | 400 | MSG-004 を No.2 に表示する |
   | 401 | ブラウザの保存領域のタイマーの状態を消す（動作中でも止める。途中のフェーズの時間は捨てる）<br>SCR-001 ログインへ遷移する（ブラウザの履歴を置き換える） |
   | 403 | MSG-004 を No.2 に表示する |
   | 404 | MSG-004 を No.2 に表示する |
   | 429 | MSG-004 を No.2 に表示する |
   | 500 | MSG-004 を No.2 に表示する |
   | 上記以外 | MSG-004 を No.2 に表示する |

4. 画面に残っているとき、No.13 の非活性を解除する。

API のパスは、[auth-openapi.json](../../api/auth-openapi.json) のパスに、その `servers` の `/api/auth` を付けて書いている。

### A3. 「再読み込み」ボタン押下

1. 共通ヘッダーの初期表示時の処理をやり直し、続けて「5. 初期表示時の処理」をやり直す。
