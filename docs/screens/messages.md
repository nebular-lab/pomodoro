# メッセージ一覧

全画面で共通のメッセージ。画面設計書からは ID で参照する。文言の中の `{v1}`、`{v2}` は変数。参照する側で、それぞれに入れる値を指定する（`MSG-004（v1: タイトル、v2: 50）`）。

| ID | 種別 | 文言 |
| --- | --- | --- |
| MSG-001 | エラー | {v1}を入力してください |
| MSG-002 | エラー | ID またはパスワードが正しくありません |
| MSG-003 | エラー | ログインの試行回数が上限を超えました。しばらくしてからもう一度お試しください |
| MSG-004 | エラー | 通信に失敗しました。時間をおいてもう一度お試しください |
