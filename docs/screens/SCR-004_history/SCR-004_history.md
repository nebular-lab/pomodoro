## 1. 概要

いつ、どのタスクに、どれだけ時間を使ったかを確認する画面。期間の単位（日・週・月・年）ごとに、作業時間の棒グラフ、完了したポモドーロの数、合計作業時間、タスクごとの合計時間を表示する。

## 2. クエリパラメータ

| パラメータ | 値 | 省略したとき | 用途 |
| --- | --- | --- | --- |
| `view` | `day`、`week`、`month`、`year` | `day`（「日」のタブを選ぶ） | 選ぶタブと、期間の単位（`GET /api/history` の `view`）。この 4 つと完全に一致しない値のときは、省略したときと同じに扱う |
| `date` | `YYYY-MM-DD` の形の、実在する日付 | 今日（日本時間） | 表示する期間の基準の日付（`GET /api/history` の `date`）。この形でない値、実在しない日付、今日（日本時間）より後の日付のときは、省略したときと同じに扱う |

省略したときと同じに扱う値が URL に付いていたときは、初期表示時の処理で URL から取り除く（「5. 初期表示時の処理」の手順 1）。

## 5. 初期表示時の処理

1. URL クエリを整える（ブラウザの履歴を置き換える）。「2. クエリパラメータ」で省略したときと同じに扱う値のパラメータ（`view`、`date`）は消す。変えるところがなければ、何もしない。
2. URL クエリ `view` に対応するタブを No.2 で選ぶ。`view` がなければ「日」を選ぶ。
3. No.8 を、URL クエリ `view` と `date` から決まる期間にする。No.10 の活性を、その期間で決める。
4. No.9、No.11、No.12、No.13、No.14、No.19、No.20、No.21 を非表示にする。
5. グラフとリストの位置に No.18 を表示する。
6. `GET /api/history`（operationId: `getHistory`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | query | `view` | URL クエリ `view`（なければ固定値 `day`） |
   | query | `date` | URL クエリ `date`（なければ今日の日付（日本時間）） |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | No.18 を非表示にする<br>`pomodoroCount` を No.9 に、`buckets[]` を No.11 に入れて表示する<br>`tasks` が 0 件なら No.19 を表示する<br>`tasks` が 1 件以上なら `totalSeconds` を No.13 に、`tasks[]` を No.14 に入れ、No.12、No.13、No.14 を表示する |
   | 401 | ブラウザの保存領域のタイマーの状態を消して、SCR-001 ログインへ遷移する |
   | 422 | No.18 を非表示にする<br>MSG-005（v1: 履歴）を No.20 に表示し、No.21 を表示する |
   | 上記以外 | No.18 を非表示にする<br>MSG-005（v1: 履歴）を No.20 に表示し、No.21 を表示する |

### A1. タブの切り替え

1. すでに選んでいるタブを押したときは、何もせずに終了する。
2. URL クエリの `view` を、選んだタブの値（「週」は `week`、「月」は `month`、「年」は `year`。「日」なら `view` を消す）に書き換える（ブラウザの履歴に追加する）。`date` は変えない。
3. 「5. 初期表示時の処理」の手順 2〜6 を行う（`view` は手順 2 で書き換えた値になる）。

### A2. 前の期間へのボタン押下

1. URL クエリの `date`（なければ今日の日付（日本時間））を、いまの単位で 1 つ前へずらした日付に書き換える（ブラウザの履歴に追加する）。`view` は変えない。

   | `view` | ずらし方 |
   | --- | --- |
   | `day`（省略したときを含む） | 1 日前 |
   | `week` | 7 日前 |
   | `month` | 前の月の同じ日。その日がない月のときは、その月の最後の日 |
   | `year` | 前の年の同じ月日。その日がないとき（2 月 29 日）は、2 月 28 日 |

2. 「5. 初期表示時の処理」の手順 3〜6 を行う（`date` は手順 1 で書き換えた値になる）。

### A3. 次の期間へのボタン押下

1. A2 と同じ処理をする。違うのは、日付を、いまの単位で 1 つ後ろへずらすこと（1 日後、7 日後、次の月の同じ日、次の年の同じ月日）。ずらした日付が今日（日本時間）より後になるときは、今日の日付にする。

### A4. 「再読み込み」ボタン押下

1. 「5. 初期表示時の処理」の手順 4〜6 を行う。

### A5. ブラウザの戻る・進むで、この画面の URL クエリが変わる

1. 「5. 初期表示時の処理」の手順 1〜6 をやり直す（変わったあとの URL クエリで、タブを選び直し、`GET /api/history` を呼ぶ）。
