## 1. 概要

ID とパスワードでログインする画面。ログインできたら、タイマー画面へ進む。入力の途中で画面を離れても、離脱確認はしない（共通ルールと違う: 保存するものがないため）。ブラウザの戻るでこの画面に戻ったときは、ID もパスワードも復元せず、空で表示する（共通ルールと違う: パスワードをブラウザの中に残さないため）。

API のパスは、[auth-openapi.json](../../api/auth-openapi.json) のパスに、その `servers` の `/api/auth` を付けて書く。

## 5. 初期表示時の処理

1. `GET /api/auth/get-session`（operationId: `getSession`）を呼ぶ。応答が返るまで、何も表示しない。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | レスポンスが `null` でないとき、すでにログインしているので、タイマー画面（画面 ID と URL は TBD）へ遷移して終了する（ブラウザの履歴を置き換える）<br>レスポンスが `null` のとき、何もしない（ログインしていないので、この画面を表示する） |
   | 400 | 何もしない（ログインはできるように、この画面を表示する） |
   | 401 | 何もしない（ログインはできるように、この画面を表示する） |
   | 403 | 何もしない（ログインはできるように、この画面を表示する） |
   | 404 | 何もしない（ログインはできるように、この画面を表示する） |
   | 429 | 何もしない（ログインはできるように、この画面を表示する） |
   | 500 | 何もしない（ログインはできるように、この画面を表示する） |
   | 上記以外 | 何もしない（ログインはできるように、この画面を表示する） |

2. No.1、No.2、No.4、No.5、No.7、No.8、No.10 を表示する。

## 6. アクション

### アクション一覧

| ID | 操作 | 対象 |
| --- | --- | --- |
| A1 | 「ログイン」ボタン押下 | No.10 |

### A1. 「ログイン」ボタン押下

1. No.3 を非表示にする。
2. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 5 | ID | 必須（前後の空白を除いた値で確かめる。空白だけは未入力とみなす） | MSG-001（v1: ID） | No.6 |
   | 8 | パスワード | 必須（空白を取り除かない値で確かめる。空白だけでも入力ありとみなす） | MSG-001（v1: パスワード） | No.9 |

3. エラーがなかった項目のエラー表示（チェック表の表示先）を非表示にする。
4. エラーがあった項目のエラー表示に、それぞれ最初の 1 件を表示する。
5. エラーがあれば、最初のエラー項目までスクロールして終了する。
6. No.10 を非活性にする。
7. `POST /api/auth/sign-in/username`（operationId: なし）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | body | `username` | No.5 の入力値 |
   | body | `password` | No.8 の入力値（前後の空白を取り除かない） |
   | body | `rememberMe` | 指定しない |
   | body | `callbackURL` | 指定しない |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | タイマー画面（画面 ID と URL は TBD）へ遷移する（ブラウザの履歴を置き換える） |
   | 400 | MSG-004 を No.3 に表示する |
   | 401 | MSG-002 を No.3 に表示する（No.5 と No.8 の入力済みの値は残す） |
   | 403 | MSG-004 を No.3 に表示する |
   | 404 | MSG-004 を No.3 に表示する |
   | 422 | MSG-002 を No.3 に表示する（ID の形式が受け付けられないときに返る。一致するアカウントがないので、401 と同じに扱う。No.5 と No.8 の入力済みの値は残す） |
   | 429 | MSG-003 を No.3 に表示する（No.5 と No.8 の入力済みの値は残す） |
   | 500 | MSG-004 を No.3 に表示する |
   | 上記以外 | MSG-004 を No.3 に表示する |

8. 画面に残っているとき、No.10 の非活性を解除する。
