## 1. 概要

ポモドーロタイマーを表示し、操作する画面。作業するタスクを選び、開始・一時停止・再開・スキップ・リセットを行う。

## 5. 初期表示時の処理

この設計書では、[storage.md](../storage.md) の値を、設定（STG-001）、タスク（STG-002）、作業記録（STG-003）、タイマーの状態（STG-004）と呼ぶ。設定とタイマーの状態は、共通ヘッダーが初期表示時の処理で読んだものを使う。「フェーズの長さ」の決め方は、[共通ヘッダーの設計書](../HDR-001_app-header/HDR-001_app-header.md)の「4. 初期表示時の処理」にある。

1. 共通ヘッダーの初期表示時の処理が終わったあと、A7 を行う（タイマーの状態に合わせて、No.1〜No.11 と画面の背景を表示する）。

## 6. アクション

### アクション一覧

| ID | 操作 | 対象 |
| --- | --- | --- |
| A1 | リセットのボタン押下 | No.3 |
| A2 | 開始のボタン押下 | No.4 |
| A3 | スキップのボタン押下 | No.5 |
| A4 | 作業するタスクの選択を変える | No.8 |
| A5 | 一時停止のボタン押下 | No.9 |
| A6 | 再開のボタン押下 | No.10 |
| A7 | タイマーの状態が変わる | - |

### A1. リセットのボタン押下

1. 動作を開始前にし、フェーズの長さ・終了予定時刻・残り秒数を `null` にする。フェーズとサイクルの回は変えない。作業記録は作らない。
2. タイマーの状態を、STG-004 に保存する。
3. A7 を行う。

### A2. 開始のボタン押下

1. ブラウザ通知を、まだ許可も拒否もしていないとき、ブラウザに通知の許可を求める（利用者が答えるのを待たずに、次の手順へ進む）。
2. フェーズの長さを、設定での、いまのフェーズの長さにし、終了予定時刻を「現在の時刻 ＋ フェーズの長さ」にし、動作を動作中にする（残り秒数は `null` のまま）。
3. タイマーの状態を、STG-004 に保存する。
4. A7 を行う。

### A3. スキップのボタン押下

動作が開始前でも、動作中でも、一時停止中でも、同じ処理をする。作業記録は作らない（ポモドーロの完了としては数えない）。ブラウザ通知の許可は、ここでは求めない（求めるのは、A2 だけ）。音も通知も出さない。

1. 共通ヘッダーの A6 の手順 3〜4 を行う（次のフェーズへ進め、開始前にする）。
2. 次のフェーズを自動スタートする設定のとき（次のフェーズが休憩なら設定の `autoStartBreak`、作業なら `autoStartWork` が `true` のとき）、A2 の手順 2 を行う。
3. タイマーの状態を、STG-004 に保存する。
4. A7 を行う。

### A4. 作業するタスクの選択を変える

1. 選択中のタスクを、選んだタスクの `id` にする（「タスクなし」を選んだときは、`null` にする）。
2. No.7 を、選んだタスクの色にする。
3. タイマーの状態を、STG-004 に保存する。

### A5. 一時停止のボタン押下

1. 「終了予定時刻 − 現在の時刻」が 0 以下のとき、一時停止せずに終了する（共通ヘッダーの A5 が、フェーズを完了にする）。
2. 残り秒数を「終了予定時刻 − 現在の時刻」（1 秒未満は切り上げ）にし、終了予定時刻を `null` にし、動作を一時停止中にする。
3. タイマーの状態を、STG-004 に保存する。
4. A7 を行う。

### A6. 再開のボタン押下

1. 終了予定時刻を「現在の時刻 ＋ 残り秒数」にし、残り秒数を `null` にし、動作を動作中にする。
2. タイマーの状態を、STG-004 に保存する。
3. A7 を行う。

### A7. タイマーの状態が変わる

この画面のアクション（A1、A2、A3、A5、A6）と「5. 初期表示時の処理」から行う。共通ヘッダーの A6（フェーズが完了する）からも行う。

1. No.1、No.2 を、いまのタイマーの状態と設定で表示する。
2. ボタンを、いまの動作に合わせて表示する。開始前なら No.4 を表示し、No.3、No.9、No.10 を非表示にする。動作中なら No.3、No.9 を表示し、No.4、No.10 を非表示にする。一時停止中なら No.3、No.10 を表示し、No.4、No.9 を非表示にする。
3. フェーズが作業で、動作が動作中か一時停止中のとき、No.8 を非活性にする。それ以外のときは、No.8 の非活性を解除する。どちらのときも、選んでいる値は残す。
4. STG-002 から、タスクを読む。値がないとき（JSON として読めないときを含む）、または配列でないときは、0 件として扱う。形式に合わない要素は、ないものとして扱う。
5. No.8 が活性で、選択中のタスクが、読んだタスクの中にないか、アーカイブされているとき、選択中のタスクを `null`（「タスクなし」）にし、タイマーの状態を、STG-004 に保存する。
6. No.8 の選択肢を、読んだタスクで作り直し、選択中のタスク（持たないときは「タスクなし」）を選んだ状態にする。No.7 を、その色にする。
7. フェーズが休憩（小休憩・長休憩）のときは、画面の背景を休憩の色にする。作業のときは、作業の色にする（フェーズの種類は、文字では表示しない。色は、実装のときにデザインとして決める）。
8. STG-003 から、作業記録を読む。値がないとき（JSON として読めないときを含む）、または配列でないときは、0 件として扱う。形式に合わない要素は、ないものとして扱う。No.11 を、読んだ作業記録で表示する。
9. `document.title` を、変えたあとの状態に合わせる（動作中なら、共通ヘッダーの A5 の手順 2 のとおり。動作中でなければ、「タイマー」）。
