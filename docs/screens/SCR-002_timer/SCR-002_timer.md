## 1. 概要

ポモドーロタイマーを表示し、操作する画面。作業するタスクを選び、開始・一時停止・再開・スキップ・リセットを行う。

## 5. 初期表示時の処理

この処理とアクションで使う「タイマーの状態」（フェーズ、サイクルの回、動作、終了予定時刻、残り秒数、選択中のタスク、作業の時間帯）と「フェーズの長さ」は、[共通ヘッダーの設計書](../HDR-001_app-header/HDR-001_app-header.md)の「4. 初期表示時の処理」に定義がある。

1. No.12、No.13 を非表示にする。
2. No.11 を表示する。
3. 共通ヘッダーの初期表示時の処理が終わるのを待つ。共通ヘッダーが設定を読み込めなかったときは、No.11 を非表示にし、MSG-005（v1: タイマー）を No.12 に表示し、No.13 を表示して終了する。
4. `GET /api/tasks`（operationId: `listTasks`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | query | `archived` | 固定値 `false` |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `tasks[]` を No.8 の選択肢に入れる |
   | 401 | ブラウザの保存領域のタイマーの状態を消して、SCR-001 ログインへ遷移して終了する |
   | 422 | No.11 を非表示にする<br>MSG-005（v1: タイマー）を No.12 に表示し、No.13 を表示して終了する |
   | 上記以外 | No.11 を非表示にする<br>MSG-005（v1: タイマー）を No.12 に表示し、No.13 を表示して終了する |

5. 選択中のタスクが、`GET /api/tasks` の `tasks[]` にないとき（アーカイブされたとき）、選択中のタスクを「タスクなし」にし、タイマーの状態を保存する。すでにある作業の時間帯のタスクは変えない。
6. No.11 を非表示にし、A8 を行う（タイマーの状態に合わせて、No.1〜No.10 と画面の背景を表示する）。

## 6. アクション

### アクション一覧

| ID | 操作 | 対象 |

| A1 | リセットのボタン押下 | No.3 |

### A1. リセットのボタン押下

1. 作業の時間帯をすべて捨てる（サーバーへは送らない）。
2. 動作を開始前にし、残り秒数を、いまの設定での、いまのフェーズの長さ（作業は `GET /api/settings` の `workMinutes`、小休憩は `shortBreakMinutes`、長休憩は `longBreakMinutes` の、それぞれ × 60）にする。フェーズとサイクルの回は変えない。
3. タイマーの状態を、ブラウザの保存領域に保存する。
4. A8 を行う。

### A2. 開始のボタン押下

1. ブラウザ通知を、まだ許可も拒否もしていないとき、ブラウザに通知の許可を求める（利用者が答えるのを待たずに、次の手順へ進む）。
2. 終了予定時刻を「現在の時刻 ＋ 残り秒数」にし、動作を動作中にする。
3. フェーズが作業のとき、作業の時間帯を 1 つ足す（開始時刻は現在の時刻、タスクは選択中のタスク、終了時刻はまだなし）。
4. タイマーの状態を、ブラウザの保存領域に保存する。
5. A8 を行う。

### A3. スキップのボタン押下

1. 作業の時間帯をすべて捨てる（サーバーへは送らない。ポモドーロの完了としては数えない）。
2. 共通ヘッダーの A5 の手順 6〜12 を行う（次のフェーズへ進める。自動スタートの設定にも従う。音と通知は出さない）。

動作が開始前でも、動作中でも、一時停止中でも、同じ処理をする。

### A4. 作業するタスクの選択を変える

1. 選択中のタスクを、選んだタスクにする（「タスクなし」を選んだときは、持たない状態にする）。
2. No.7 を、選んだタスクの色にする。
3. タイマーの状態を、ブラウザの保存領域に保存する。

すでにある作業の時間帯のタスクは変えない。一時停止中に変えたときは、再開したあとの時間帯から、選んだタスクになる。

### A5. 一時停止のボタン押下

1. 「終了予定時刻 − 現在の時刻」が 0 以下のとき、一時停止せずに終了する（共通ヘッダーの A5 が、残り時間が 0 になったときの処理を行う）。
2. 残り秒数を「終了予定時刻 − 現在の時刻」（1 秒未満は切り上げ）にし、動作を一時停止中にする。
3. フェーズが作業のとき、最後の作業の時間帯の終了時刻を、現在の時刻にする。
4. タイマーの状態を、ブラウザの保存領域に保存する。
5. A8 を行う。

### A6. 再開のボタン押下

1. A2 の手順 2〜5 を行う。

### A7. 「再読み込み」ボタン押下

1. 共通ヘッダーの初期表示時の処理をやり直し、続けて「5. 初期表示時の処理」をやり直す。

### A8. タイマーの状態が変わる

この画面のアクション（A1、A2、A3、A5、A6）と「5. 初期表示時の処理」の手順 6 から行う。共通ヘッダーの A5（残り時間が 0 になる）と A6（ほかのタブで、タイマーの状態が変わる）からも行う。

1. 「5. 初期表示時の処理」の手順 6 にまだ達していないとき（読み込み中、または読み込みのエラーを表示しているとき）は、何もせずに終了する。
2. No.1、No.2 を、いまのタイマーの状態で表示する。No.6、No.7、No.8 も表示する。
3. ボタンを、いまの動作に合わせて表示する。開始前なら No.4 を表示し、No.3、No.9、No.10 を非表示にする。動作中なら No.3、No.9 を表示し、No.4、No.10 を非表示にする。一時停止中なら No.3、No.10 を表示し、No.4、No.9 を非表示にする。No.5 は、どの動作でも表示する。
4. フェーズが作業で、動作が動作中のとき、No.8 を非活性にする。それ以外のときは、No.8 の非活性を解除する。どちらのときも、選んでいる値は残す。
5. No.8 を、選択中のタスク（持たないときは「タスクなし」）を選んだ状態にし、No.7 を、その色にする。
6. フェーズが休憩（小休憩・長休憩）のときは、画面の背景を休憩の色にする。作業のときは、作業の色にする（フェーズの種類は、文字では表示しない。色は、実装のときにデザインとして決める）。
7. 共通ヘッダーの A7 を 1 回行う（`document.title` を、変えたあとの状態に合わせる）。
